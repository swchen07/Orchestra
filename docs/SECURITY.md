# Security Policy

Orchestra is an independent extension of Open WebUI. Report vulnerabilities in
Orchestra privately through [GitHub Security Advisories](https://github.com/swchen07/Orchestra/security/advisories/new).
Do not include credentials, private chats or local runtime databases in public issues.

For vulnerabilities affecting unmodified upstream Open WebUI, follow its
[security policy](https://docs.openwebui.com/security/security-policy/) and
[private reporting channel](https://github.com/open-webui/open-webui/security/advisories/new).

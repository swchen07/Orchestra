# Orchestra / Open WebUI provenance

Orchestra extends the source of https://github.com/open-webui/open-webui,
starting from upstream commit `33c1978` (2026-10-25).

Original authors: Timothy Jaeryang Baek / Open WebUI Inc. and upstream contributors.
Orchestra is an independent extension, not an official Open WebUI release.

Extensions include framework/provider/model selection, native runtime adapters,
composable workflow nodes and actions, persistent module context, execution
activity, isolated coding workspaces, versioned artifacts, evaluation/integration,
and attributed usage records.

The upstream `LICENSE`, `LICENSE_HISTORY`, `LICENSE_NOTICE`, contributor agreement
and vendored third-party notices remain in the repository. This notice does not
relicense upstream code or grant an exception to its branding requirements.
The web interface retains Open WebUI branding. See LICENSE for the actual terms.

The original upstream README is retained as `README.upstream.md`.
Local accounts, credentials, databases, runtime logs and personal validation
records are not part of the public source distribution.
